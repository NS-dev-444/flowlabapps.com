SyntaxPad

SyntaxPad is a lightweight, native macOS editor for notes, code, configuration files and Markdown — built entirely on Apple frameworks, with no Electron and no web runtime.

Overview

A fast, native Mac text editor.

It is not trying to replace Xcode or VS Code. It is the editor you reach for to open a config file, jot a note, read someone else's source, or write Markdown — and it opens instantly, every time.

Tabs, syntax highlighting, a background find-and-replace that will not freeze on a pathological regex, and a Markdown preview that renders locally under a strict content security policy.

Your unsaved scratch tabs survive a quit. Your open files come back where you left them.

Features

What it does

01Native and fast

100% AppKit and SwiftUI. No Electron, no bundled browser, no cross-platform runtime.

02Tabs and session restore

Unsaved scratch tabs and window state come back next launch.

03Syntax highlighting

For source files, configuration formats and Markdown.

04Find and replace

Runs on a background queue behind a debounce, so a slow regex cannot hang the app.

05Local Markdown preview

Rendered on your Mac under a strict CSP that blocks scripts and network requests entirely.

06Large files

Built to stay responsive on files that make lighter editors struggle.

Privacy at a glance

This app collects no data

SyntaxPad collects no data. No accounts, no analytics, no telemetry, no crash reporting, no advertising, and no network connections of any kind. Your documents never leave your Mac.
